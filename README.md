# 美食大王大作战

仿「大便超人 / Doodieman」的发泄小游戏：公主对战可自由命名的鼠王，点击招式按钮投掷美食、冲上去近身敲打或用意面抽打，没有血量、计时和关卡，想玩多久玩多久。

**线上地址**：https://vicispj.github.io/meishi-dazhan/
**GitHub 仓库**：https://github.com/Vicispj/meishi-dazhan

## 运行

- 直接双击 `index.html` 即可在浏览器里玩（本地单机，无需联网）。
- 也可以在文件夹里执行 `python -m http.server 8787`，然后访问 `http://127.0.0.1:8787/`。

首次进入会让你给鼠王起名（最多 12 字）。名字会写进网址参数，例如：

```
https://你的域名/?name=胖厨子
```

别人打开带 `?name=` 的链接，就会看到同一个名字。页面右上角「分享」按钮会生成带当前名字的链接：HTTPS 手机上调起系统分享面板；HTTP（如 COS 默认域名）或电脑上会弹出链接框，可一键复制或长按复制。直接发送本地 `file://` 文件时无法生成可分享链接，需要先部署到网上。

## 玩法

左下/底部 12 个招式按钮，由简到繁：

1. 砸蛋糕 2. 苹果弹弓 3. 法棍冲刺 4. 意面抽打
5. 披萨飞盘 6. 冰淇淋炮 7. 甜品暴雨 8. 火锅喷泉
9. 平底锅拍击 10. 擀面杖旋风 11. 满汉全席 12. 神秘料理

其中 3 / 4 / 9 / 10 是近身动作：公主会冲到鼠王面前挥法棍、用长意面抽打、拿平底锅拍、抡擀面杖连击，再跑回原位。

鼠王有一套受击反应：压扁、甩头、踢腿、甩尾、帽子被震飞、眼泪、绕头星星、表情切换（X 眼 / 痛苦 / 震惊 / 眩晕），被打多了还会冒出台词（「别打了！」「我错了！」）。命中次数越多反应越夸张，但没有血量或连击计分。

键盘数字键 1–9、0、-、= 也可以出招。右上角：分享 / 改名 / 音效开关 / 打扫（清除食物残渣并重置鼠王）。

## 技术说明

- 单文件 `index.html`，零外部依赖、零图片资源：角色与食物全部为内联 SVG 矢量绘制，音效全部由 WebAudio 实时合成。
- 适配横屏；竖屏会提示旋转手机。手机横屏下舞台按比例完整显示。
- 名字存 `localStorage`，分享链接用 `?name=` 传递。
- 无后端、无排行榜、无数据上传。

## 已知限制 / 下一步

- 美术仍是内联 SVG 的手绘感矢量（已加渐变、阴影、细节、背景道具），可继续替换为正式手绘素材（PNG/序列帧）。

- 可扩展：镜头推拉、更多近身连招、鼠王更多台词/彩蛋、全屏按钮。

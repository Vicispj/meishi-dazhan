# 美食大王大作战

公主大战可自由命名的鼠王，点击招式按钮投掷各种美食。仿 Doodieman 的固定站位发泄小游戏，无血量、无计时、无关卡。

**在线玩**：https://Vicispj.github.io/meishi-dazhan/?name=胖厨子

- 12 个招式：砸蛋糕 / 苹果弹弓 / 番茄三连 / 法棍连打 / 披萨飞盘 / 意面套索 / 冰淇淋炮 / 甜品暴雨 / 火锅喷泉 / 后厨大乱斗 / 满汉全席 / 神秘料理
- 名字写在链接 `?name=` 参数里，改名后分享链接同步
- 单文件 `index.html`，零依赖，WebAudio 合成音效，手机横屏游玩
